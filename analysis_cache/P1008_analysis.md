# P1008 详细题解

本题要求将1到9这9个数字分成3组，组成三个三位数，且这三个数满足1:2:3的比例。由于三个数的比例已经确定，我们只需要枚举最小的那个三位数（即第一个数），然后计算出另外两个数（第一个数的2倍和3倍），再判断这三个数是否恰好使用了1到9的所有数字且不重复。

步骤如下：
1. 确定第一个数的范围：最小为123（1,2,3），最大为329（因为329*3=987，超过则第三个数不是三位数）。因此第一个数的范围是123到329。
2. 遍历这个范围内的每一个数i，计算2*i和3*i。
3. 检查i, 2*i, 3*i这三位数的各位数字是否恰好是1到9的排列，且不重复。可以使用一个大小为10的数组（或布尔数组）来标记数字是否出现过。例如，初始化一个数组flag[10]为0，然后遍历三个数的每一位，将对应数字的标记置为1。最后检查flag[1]到flag[9]是否全部为1，且没有重复数字（即flag[0]为0，且各个数字的标记和为9）。
4. 如果满足条件，则输出这三个数。

注意：由于第一个数i乘以2和3后可能包含0，所以还需要检查三个数中是否包含0（如果包含0则不符合条件，因为题目要求用1到9的数字）。可以通过检查flag[0]是否为0来排除0的出现。

优化：实际上，当i乘以2和3后，可能会出现数字重复，所以需要确保三个数的所有数字都是唯一的。我们可以用一个字符串来拼接这三个数，然后检查字符串中是否同时包含1到9的所有字符且没有重复。例如，将i, 2*i, 3*i三个数转为字符串连接，然后检查字符串长度是否为9，并且每个字符都在'1'到'9'之间且不重复。

通过以上方法，我们可以高效地找到所有满足条件的三位数组合。

# 参考代码 (cpp)

```cpp
#include <iostream>
#include <cstring>
using namespace std;

int main() {
    // 遍历第一个三位数的可能范围：123到329
    for (int i = 123; i <= 329; ++i) {
        bool used[10] = {false}; // 标记数字1-9是否使用过
        int j = i * 2;
        int k = i * 3;
        // 分别检查i, j, k的每一位数字
        int num = i;
        for (int m = 0; m < 3; ++m) {
            used[num % 10] = true;
            num /= 10;
        }
        num = j;
        for (int m = 0; m < 3; ++m) {
            used[num % 10] = true;
            num /= 10;
        }
        num = k;
        for (int m = 0; m < 3; ++m) {
            used[num % 10] = true;
            num /= 10;
        }
        // 检查是否1-9都使用过且没有使用0
        bool valid = true;
        for (int d = 1; d <= 9; ++d) {
            if (!used[d]) {
                valid = false;
                break;
            }
        }
        if (valid) {
            cout << i << " " << j << " " << k << endl;
        }
    }
    return 0;
}
```
