# P1238 详细题解

本题是一个经典的迷宫路径搜索问题，要求找出从起点到终点的所有不重复路径，并按照特定的优先级顺序（左、上、右、下）进行探索。如果没有找到任何路径，则输出-1。

1. **问题分析**：
   - 我们需要在一个 m×n 的网格中移动，网格中的 `1` 表示可通行，`0` 表示墙壁。
   - 移动的方向是上下左右，但必须按照固定的优先级顺序探索：左、上、右、下。
   - 路径不能包含重复的点，即每个点只能访问一次。
   - 当到达终点时，需要输出完整的路径。
   - 如果找不到任何路径，输出 -1。

2. **算法选择**：
   - 深度优先搜索（DFS）是解决此类问题的自然选择。通过递归的方式，从起点出发，按照优先级顺序探索每个方向，直到找到终点或所有路径都已探索完毕。
   - 为了避免重复访问同一个点，我们需要在访问时将该点标记为已访问（例如，将其值设为0），并在回溯时恢复原始值。

3. **步骤**：
   - **输入处理**：读取迷宫的尺寸、迷宫本身、起点和终点的坐标。
   - **方向设置**：定义四个方向的数组，分别代表左、上、右、下的偏移量。例如，左方向可以表示为 `(0, -1)`，上方向为 `(-1, 0)`，右方向为 `(0, 1)`，下方向为 `(1, 0)`。
   - **DFS搜索**：从起点开始，递归地探索每个方向。
     - 检查当前点是否在迷宫范围内且可通行（值为1）。
     - 如果当前点是终点，记录路径并返回。
     - 否则，按照优先级顺序探索四个方向，将该点标记为已访问，然后递归探索。递归结束后，恢复该点的状态（回溯）。
   - **路径记录**：在DFS过程中，使用一个数组或栈来记录当前路径。当到达终点时，将路径格式化为题目要求的输出形式（例如，`(x1,y1)->(x2,y2)`）。
   - **结果输出**：如果找到至少一条路径，输出所有路径；否则输出-1。

4. **优化与注意事项**：
   - **边界检查**：确保每次移动时不会超出迷宫的边界。
   - **标记与回溯**：在访问点时立即标记为已访问，避免重复访问；在递归返回后恢复其状态，以便其他路径可以探索该点。
   - **输出格式**：注意输出格式，包括括号、逗号、箭头的正确使用，以及数字的直接输出（无需将数字转为字符）。
   - **方向优先级**：严格按照左、上、右、下的顺序探索，以确保输出的路径顺序正确。

5. **复杂度分析**：
   - 时间复杂度：在最坏情况下（迷宫全为1），DFS会探索所有可能的路径，复杂度为 O(4^(m*n))，因为每个点最多有4个选择。但由于限制路径不能重复，实际复杂度会低于此，但仍然可能非常高（如题目备注所示）。
   - 空间复杂度：O(m*n)，主要用于存储迷宫和路径记录。递归栈的深度最多为 m*n。

通过上述步骤，我们可以系统地解决迷宫路径搜索问题，并输出所有可行路径。

# 参考代码 (cpp)

```cpp
#include <iostream>
#include <vector>

using namespace std;

int m, n;
int maze[20][20]; // 迷宫地图，0表示墙，1表示路
int startX, startY;
int endX, endY;
bool foundPath = false;

// 记录路径，最多有 m*n 个点
vector<pair<int, int>> path;

// 方向数组：左、上、右、下
int dx[] = {0, -1, 0, 1};
int dy[] = {-1, 0, 1, 0};

void printPath() {
    for (int i = 0; i < path.size(); ++i) {
        cout << "(" << path[i].first << "," << path[i].second << ")";
        if (i != path.size() - 1) {
            cout << "->";
        }
    }
    cout << endl;
}

void dfs(int x, int y) {
    // 到达终点，输出路径
    if (x == endX && y == endY) {
        printPath();
        foundPath = true;
        return;
    }

    // 按照左、上、右、下的顺序探索
    for (int i = 0; i < 4; ++i) {
        int nx = x + dx[i];
        int ny = y + dy[i];

        // 检查边界和是否可通行
        if (nx >= 1 && nx <= m && ny >= 1 && ny <= n && maze[nx][ny] == 1) {
            // 标记为已访问
            maze[nx][ny] = 0;
            path.emplace_back(nx, ny);

            dfs(nx, ny);

            // 回溯，恢复状态
            path.pop_back();
            maze[nx][ny] = 1;
        }
    }
}

int main() {
    cin >> m >> n;
    for (int i = 1; i <= m; ++i) {
        for (int j = 1; j <= n; ++j) {
            cin >> maze[i][j];
        }
    }
    cin >> startX >> startY;
    cin >> endX >> endY;

    // 起点标记为已访问
    maze[startX][startY] = 0;
    path.emplace_back(startX, startY);

    dfs(startX, startY);

    if (!foundPath) {
        cout << -1 << endl;
    }

    return 0;
}
```
