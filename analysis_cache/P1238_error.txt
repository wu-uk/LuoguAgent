n        d. 按照左、上、右、下的优先级顺序遍历四个方向。对于每个方向 `i`（从 0 到 3）：\n           i. 计算下一个点的坐标 `next_x = x + dx[i]` 和 `next_y = y + dy[i]`。\n          ii. **剪枝：** 检查下一个点 `(next_x, next_y)` 是否可以走。条件是：\n              - 在迷宫边界内：`1 <= next_x <= m` 且 `1 <= next_y <= n`。\n              - 是可通行的点：`maze[next_x][next_y] == 1`。\n              如果满足条件，则递归调用 `dfs(next_x, next_y, step + 1)`。\n        e. **回溯：** 当四个方向都探索完毕，或者从某个方向递归返回后，需要撤销对当前点的访问标记，以便其他路径可以经过该点。即 `maze[x][y] = 1`。
