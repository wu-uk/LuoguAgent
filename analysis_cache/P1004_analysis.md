# P1004 详细题解

本题要求在一个 N×N 的方格图中，从左上角 (1,1) 到右下角 (N,N) 走两次，每次只能向右或向下移动，求两条路径所经过的方格数字之和的最大值。一个关键点是，如果一个方格被两条路径都经过，它的数字只能被计算一次。

这是一个典型的动态规划问题。我们可以将两次路径的求解合并到一个 DP 状态中，以避免后一次路径受到第一次路径取数后状态改变的影响。

**1. 状态定义**：
我们定义一个四维数组 `dp[i][j][k][l]` 表示第一条路径走到 `(i, j)`，第二条路径走到 `(k, l)` 时，两条路径可以取得的数字和的最大值。

**2. 状态转移**：
要到达状态 `(i, j, k, l)`，两个点各自都是从上方或左方转移过来的。因此，我们可以从前面的四个状态转移而来：
- `dp[i-1][j][k-1][l]`: 路径1从上方来，路径2从上方来。
- `dp[i-1][j][k][l-1]`: 路径1从上方来，路径2从左方来。
- `dp[i][j-1][k-1][l]`: 路径1从左方来，路径2从上方来。
- `dp[i][j-1][k][l-1]`: 路径1从左方来，路径2从左方来。

我们取这四个状态的最大值，然后加上当前两个格子的贡献。这里的贡献需要分两种情况讨论：
- **情况A：两个格子的位置不同** `(i, j) != (k, l)`
  此时两条路径没有重合，可以同时取走两个格子的数字。总贡献为 `grid[i][j] + grid[k][l]`。
- **情况B：两个格子的位置相同** `(i, j) == (k, l)`
  此时两条路径在同一个格子汇合，根据题意，这个格子的数字只能被计算一次。总贡献为 `grid[i][j]`。

因此，状态转移方程为：
`dp[i][j][k][l] = max(dp[i-1][j][k-1][l], dp[i-1][j][k][l-1], dp[i][j-1][k-1][l], dp[i][j-1][k][l-1]) + current_value`
其中 `current_value` 的计算方式如上所述。

**3. 初始化**：
DP 数组所有值初始化为0。边界情况 `i,j,k,l` 为1时会自然处理，因为当坐标为0时，DP值也为0。

**4. 循环顺序**：
我们使用四重循环遍历 `i, j, k, l` 从 1 到 N，依次计算所有状态的值。由于我们计算 `dp[i][j][k][l]` 时，只依赖于 `i-1` 或 `j-1` 的状态，所以按照 1 到 N 的顺序循环是正确的。

**5. 最终答案**：
题目要求的是两条路径都从 A(1,1) 到 B(N,N) 的最大和，因此，我们最终的结果就是 `dp[N][N][N][N]`。

# 参考代码 (cpp)

```cpp
#include <iostream>
#include <algorithm>

// 使用命名空间 std
using namespace std;

int main() {
    // 提高 cin/cout 效率
    ios_base::sync_with_stdio(false);
    cin.tie(NULL);

    int n;
    cin >> n;

    // 方格图，范围1~9，所以开10x10数组即可
    int grid[10][10] = {0};

    // 读入数据，以 0 0 0 结束
    int x, y, z;
    while (cin >> x >> y >> z && !(x == 0 && y == 0 && z == 0)) {
        grid[x][y] = z;
    }

    // DP数组
    // dp[i][j][k][l]: 路径1到(i,j)，路径2到(k,l)的最大和
    // N最大为9，数组大小可以稍微开大一点，比如15x15x15x15，防止数组越界
    int dp[15][15][15][15] = {0};

    // 四重循环，遍历所有可能的状态
    for (int i = 1; i <= n; ++i) {
        for (int j = 1; j <= n; ++j) {
            for (int k = 1; k <= n; ++k) {
                for (int l = 1; l <= n; ++l) {
                    // 从前一个状态的最大值转移而来
                    // max中四个参数分别对应两种路径各自的两种来源（上或左）的组合
                    int max_prev = max({
                        dp[i - 1][j][k - 1][l], // 路径1从上, 路径2从上
                        dp[i - 1][j][k][l - 1], // 路径1从上, 路径2从左
                        dp[i][j - 1][k - 1][l], // 路径1从左, 路径2从上
                        dp[i][j - 1][k][l - 1]  // 路径1从左, 路径2从左
                    });

                    // 加上当前格子的贡献
                    // 必须先加上第一个格子的值
                    dp[i][j][k][l] = max_prev + grid[i][j];

                    // 如果两个格子不是同一个位置，则可以加上第二个格子的值
                    // 如果是同一个位置，则只加一次，不能重复计算
                    if (i != k || j != l) {
                        dp[i][j][k][l] += grid[k][l];
                    }
                }
            }
        }
    }

    // 输出最终结果：两条路径都到达右下角(N,N)的最大和
    cout << dp[n][n][n][n] << endl;

    return 0;
}
```
